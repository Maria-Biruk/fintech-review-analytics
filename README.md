## Task 2: Sentiment and Thematic Analysis

This phase applied NLP techniques to analyze 2735 Google Play Store reviews.

### Techniques Used:

- TextBlob sentiment analysis
- Keyword frequency extraction
- Thematic clustering using word frequency

### Outputs:

- Sentiment classification (Positive, Neutral, Negative)
- Complaint keyword extraction
- Feature request analysis
- Bank-level comparison

### Key Insight:

Systemic issues in performance and transaction reliability affect all three banks, with BOA showing the highest dissatisfaction levels.
